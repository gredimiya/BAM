# 📚 BAM - Bilan d'Achat de Manga

Une application web simple pour gérer votre collection de mangas avec Streamlit.

## 🚀 Démarrage Rapide (30 secondes)

```bash
git clone https://github.com/yourusername/BAM.git && cd BAM
chmod +x install.sh run.sh
./install.sh && ./run.sh
```

Puis ouvrez : **http://localhost:8501**

👉 **[Voir le guide complet](QUICKSTART.md)**

## ✨ Fonctionnalités

- 📝 **Ajouter des mangas** - Titre, auteur, édition
- 📚 **Gérer les tomes** - Numéro, prix, date d'achat
- 📊 **Visualisations** - Graphiques et statistiques
- 📋 **Tableau de données** - Vue complète et export CSV
- 🔍 **Filtres** - Par auteur, édition, dates

## 📋 Prérequis

- Python 3.8+
